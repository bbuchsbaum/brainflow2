# Folder opening: first delivery

Delivered in the working tree on 2026-09-06. This implements the single-folder entrance and review from [the loading plan](neurotabs-open-set-workflow.md); it does not complete all four slices.

## Try the updated application

Right-click a folder in Files and choose **Open in Set Studio…**. Alternatively, select a folder and use **Use selected folder** in Studio's empty state, or choose a local folder there.

The center pane shows proposed members and image columns. Original relative filenames stay intact, including nested session paths. Change the organization using the dropdown; inspect individual source paths by clicking cells. Missing images stay unavailable. **Open set** rechecks assignments and then replaces the study; **Cancel** preserves the existing study. Regex and depth/size limits are under Advanced options.

The running desktop application must use the updated source/build. No installed application was replaced during this delivery.

## Implementation boundaries

- A folder path is captured explicitly, including the existing mount-backed remote I/O path. Display provenance is snapshotted separately so the review shows the host's path rather than an internal staging path.
- Generic folder/file organization uses `member` and `image` captures. It preserves filename distinctions and does not infer a statistical role or participant identity. Explicit empty required roles means no statistical-role prerequisite.
- Pending imports reuse the existing Studio import machine and backend import contract. Changed settings, cancellation, panel teardown and late responses cannot publish an old draft. Confirmation re-enumerates assignments and asks for review again if they changed; this is not a frozen content-hash snapshot of all images.
- Discovery performs listing without payload downloads by default. Remote enumeration has an entry bound and optional cancellation tickets; existing owned SFTP adapters finish their current operation. Local listing runs on a bounded blocking worker; cancellation discards its result while that worker finishes. Search depth counts relative path components consistently for local and remote inventories; depth 1 includes files directly in the selected folder.
- Upstream truncation propagates through validation and blocks opening. Duplicate assignments also block opening. Header-free discovery cannot grant comparison readiness, and one sampled remote header does not certify every member. Actual operations retain their required source/support checks.
- Existing table and full NeuroTabs manifest import routes remain available. They retain their existing review presentation in this slice.
