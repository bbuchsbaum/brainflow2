BIDS browser, round 4

Round 3 was approved by the first four critics. Two new critics then reviewed it independently: Josef Albers with a Bauhaus panel (colour, form, type) and Mike Bostock (encodings, interaction, implementation). Both approved with fixes, and between them they raised five blocking items. This round answers all of them.

The main change is that the FD marks are now honest. Each run has one FD trace, and every FD number and mark on the page is computed from it: the sparklines (a min–max band per pixel column, on 0–1 mm, with a tick wherever a value is clipped), the session means, the findings, the dock and the Inspector. The Inspector's FD trace, carpet and events now share one time axis and one crosshair.
