BIDS browser, round 3

All four critics approved round 2 with fixes. This round answers every blocking item and shows the states nobody had seen yet: the shared lens and command palette, exclusion with undo, the Files panel following the selection, and a 400-participant dataset while it is still scanning.

One disagreement needed a ruling. Jobs wanted no filter bar and no Runs tab; the Linear designer wanted one filter object, saved views and ⌘K. The answer is a single lens: it is set by clicking a claim, a finding or a ⌘K result, never typed into a permanent bar. It shows as one chip with highlight or only, applies to every view, and can be saved. The runs in the lens appear in the bottom dock, with the same keyboard map in every view.
