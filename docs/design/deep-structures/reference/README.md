# Deep-structure view: reference screens

Design mocks at 1440 x 900 from the end of the hill climb (round 3 plus one
targeted pass). The brain images and every number are computed from public
data; the app shell is a static mock modelled on the Integrated layout. See
[`../critiques.md`](../critiques.md) for what they are evidence of, and
[`tools/design/deep_structures`](../../../../tools/design/deep_structures/README.md)
to regenerate them.

| File | State |
| --- | --- |
| `main.png` | Hippocampus selected; cut across the hippocampal long axis, 18 mm from the head. |
| `thalamus.png` | Thalamus selected; coronal cut; the case with no template surfaces. |
| `round-0-a.png` | Round 0, direction "Cut": a notch along the long axis. |
| `round-0-b.png` | Round 0, direction "Sheet": deep structures on the inflated medial wall. |
| `round-0-c.png` | Round 0, direction "Sections": coronal small multiples in one drawing language. |
| `manifest.json` | Decisions, changes by critic and rank, and what was not done. |
