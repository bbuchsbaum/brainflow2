# Browser qualification fixtures

Generated by `python3 tools/generate_browser_fixture.py`, using only Python's
standard library. No participant or patient data is included.

`oblique.nii` and `oblique.nii.gz` contain the same 5×7×9 f32 array:
`value(i,j,k) = i + 10*j + 100*k`, with `i` stored fastest. The NIfTI sform is
`world = (10 - 2*j, -7 + 3*i, 5 + 4*k)` mm. Its centre is `(4,-1,21)` mm,
range `[0,864]`, and voxel-edge bounds are `(-3,-8.5,3)` to `(11,6.5,39)` mm.

`frame.json` requests a 7×5 nearest-neighbour axial raster at k=4. Pixel `(x,y)`
must sample voxel `(y,x,4)`, value `400 + 10*x + y`. This tests axis rotation,
anisotropy, physical scalar units, row order and the single readback Y flip.
The native host test exports the actual packet for browser byte comparison.

`oblique4d.nii` and its gzip copy add three frames on the same spatial grid:
`value(i,j,k,t) = i + 10*j + 100*k + 1000*t`. The header declares a two-second
time spacing. Tests select frames 0, 2, 1, 0 and use a fixed [0,2864] window.
The expected raster remains `(400 + 10*x + y + 1000*t) / 2864 * 255`.

`labels.nii` and its gzip copy use the same grid and label intent 1002:
`label(i,j,k) = [0,17,1024,2047][(i+j) % 4]`. The TSV supplies red, green and
blue for the nonzero IDs. Tests shift the raster by 0.4 voxel along i, request
linear interpolation, and still require exact nearest-neighbour label colors.
Label zero must transmit an underlying scalar layer. Invalid f64 labels are
constructed in tests, including 17.00000001, which rounds to 17 through f32.
